# QuickNotes

QuickNotes is a simple web application for creating, searching and deleting notes. It allows users to organize notes into categories and stores them in localStorage so they remain after refreshing the page.

## Features

- Add notes
- Delete notes
- Search notes
- Categories
- Local storage
- Responsive layout

## Running the project

1. Clone the repository.
2. Open the project folder.
3. Open index.html in your browser.

## What I learned

- Using JavaScript to manipulate the DOM.
- Saving and loading data using localStorage.
- Creating responsive layouts with Flexbox and CSS media queries.
